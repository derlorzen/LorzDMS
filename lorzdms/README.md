# LorzDMS

KI-gestütztes Dokumentenmanagement mit Google Drive als führendem Archiv.

- Erfasst Dokumente aus Gmail (nur lesend), Google-Drive-Eingangsordnern, `/share/lorzdms/inbox` und per Upload
- Lokale OCR (OCRmyPDF/Tesseract), Volltextsuche
- Ablage per Regeln und optional KI (Ollama, OpenAI-kompatibel, Anthropic) in bestehende Drive-Ordner
- Beobachtungsmodus, manuelle Prüfung, Rückgängig-Funktion, Verarbeitungsjournal

Version 0.1.0 ist eine **Vorabversion**. Details und Einschränkungen in der Dokumentation (Reiter „Dokumentation“).
